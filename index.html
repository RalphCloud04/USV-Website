About the USV Monitoring System

This dashboard is designed to monitor an Unmanned Surface Vehicle operating in Malabon Lake. It provides a simple interface for viewing system status, live camera information, waste composition, GPS location, and water quality data.

System Purpose

The system is intended to help monitor the condition and location of the USV while collecting useful environmental information from the lake.

Monitored Information

The dashboard displays container load, battery life, camera feed status, waste composition, GPS coordinates, water temperature, total dissolved solids, and pH level.
